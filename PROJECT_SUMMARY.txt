1. Установка зависимостей:
   $ pip install -r requirements.txt

2. Запуск приложения:
   $ python run.py
   Доступно по адресу: http://localhost:5000

3. Запуск тестов:
   $ pytest              # Все тесты
   $ pytest -v           # Подробный вывод
   $ pytest --cov=app    # С покрытием кода
